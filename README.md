# StudyBot

Application gratuite de révision en français : fiches simples, cartes mémoire et quiz générés à partir du texte de cours.

## Utilisation
Ouvrir le site, coller un cours dans **Mes cours**, puis créer une fiche et des cartes. Les données sont conservées dans le navigateur de l'appareil.

## Installation
StudyBot est une PWA : sur iPhone, ouvrir avec Safari puis **Partager → Sur l’écran d’accueil** ; sur Android, utiliser **Installer l’application** dans Chrome. HTTPS est nécessaire.

## Limites
La génération est heuristique et n'est pas une IA. Pas de compte ni synchronisation. Les publicités et paiements ne sont pas activés.
